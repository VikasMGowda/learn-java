The Algorithms Way: 50 array questions, each worked through the 8 steps
Algorithms · algorithms365.com

PDFs/        One PDF per question: 01-25 integer arrays, 26-50 character arrays.
             Each PDF walks through Read, Visualise (paper slips), Signature,
             Test cases, Plain-English explanation, Clean code, Dry run, Reflect.

Java_Stubs/  One Java file per question (Q01_... to Q50_...). Each file runs on its own.
             1. Open the file and write your code inside the function marked TODO.
                Do not change the function's signature.
             2. The function must RETURN the answer. Do not print it.
             3. Run it:   java Q01_CountOddEven.java
                (or:      javac Q01_CountOddEven.java   then   java Q01_CountOddEven)
             4. Each test prints PASS, FAIL (with expected vs returned), ERROR, or TODO.
                Keep going until every test case passes.

The test cases in each Java file are exactly the ones in Step 4 of the matching PDF.
Requires Java 11 or newer.
